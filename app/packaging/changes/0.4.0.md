Faster builds, optionally: two new checkboxes below the app list.

- **Also build the disk image (.dmg)**: off by default. The app itself is finished before the disk image, so skipping it saves time.
- **Faster build: leave out the command-line tool, if possible**: on by default. Where an app's build script allows it, the separate command-line tool is not compiled. Otherwise it is built as before.

`install.sh` on its own still builds the command-line tool; use `CRAFT_SKIP_CLI=1` to leave it out and `CRAFT_DMG=1` to build the disk image. The two options are independent.
